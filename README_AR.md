# بوت تيليجرام لتنزيل وسائط YouTube

مشروع Python متعدد الملفات، جاهز للنشر على Railway باستخدام Dockerfile.

## الميزات
- استقبال رابط YouTube والتحقق من نطاقه.
- عرض عنوان الفيديو ومدته.
- تنزيل فيديو بجودات 360p و480p و720p و1080p حسب المتاح.
- استخراج الصوت بصيغة MP3.
- عرض تقدم التنزيل.
- حد أقصى لحجم الملف قبل إرساله إلى تيليجرام.
- إحصائيات للمشرف عبر `/stats`.
- تخزين المستخدمين والعمليات في SQLite.

## تنبيه قانوني
استخدم المشروع فقط مع المحتوى الذي تملكه أو لديك إذن صريح بتنزيله، والتزم بحقوق النشر وشروط استخدام YouTube والقوانين المحلية. لا يضمن المشروع إمكانية تنزيل كل فيديو؛ فقد تكون بعض المقاطع خاصة أو مقيدة أو غير متاحة.

## التشغيل محلياً
يتطلب Python 3.11 أو أحدث وFFmpeg.

1. ثبّت FFmpeg على جهازك.
2. أنشئ بيئة افتراضية:
   ```bash
   python -m venv .venv
   ```
3. فعّل البيئة الافتراضية ثم ثبّت المكتبات:
   ```bash
   pip install -r requirements.txt
   ```
4. انسخ `.env.example` إلى `.env` وضع توكن BotFather ومعرّف تيليجرام الخاص بك في `ADMIN_IDS`.
5. عيّن متغيرات البيئة من الطرفية أو استخدم أداة تحميل `.env` محلياً.
6. شغّل:
   ```bash
   python main.py
   ```

ملاحظة: ملف `.env` لا يُحمّل تلقائياً في هذا القالب. على Railway أضف المتغيرات من تبويب Variables. للتشغيل المحلي صدّر المتغيرات إلى بيئتك أو أضف `python-dotenv` واستخدم `load_dotenv()` في `main.py`.

## النشر على Railway
1. ارفع كامل مجلد المشروع إلى مستودع GitHub خاص أو عام.
2. في Railway اختر New Project ثم Deploy from GitHub Repo.
3. اختر المستودع.
4. من Variables أضف:
   - `BOT_TOKEN`: التوكن الذي حصلت عليه من BotFather.
   - `ADMIN_IDS`: رقم حسابك في تيليجرام، ويمكن تركه فارغاً.
   - `MAX_UPLOAD_MB`: القيمة الافتراضية `49`.
   - `DB_PATH`: `/data/bot.db`.
5. إذا أردت بقاء قاعدة البيانات بعد إعادة النشر، أضف Volume في Railway واربطه بالمسار `/data`.
6. ابدأ النشر. سيستخدم Railway ملف Dockerfile لتثبيت FFmpeg والمكتبات وتشغيل البوت.

هذا البوت يستخدم Telegram long polling، لذلك لا يحتاج إلى دومين أو إعداد Webhook.

## معرفة Telegram User ID
يمكنك استخدام بوت موثوق يعرض رقم حسابك، ثم وضع الرقم في `ADMIN_IDS`. لا تضع اسم المستخدم بدلاً من الرقم.

## حدود الإرسال
إعداد المشروع الافتراضي يرفض إرسال ملف أكبر من 49 MB لتقليل فشل الرفع عبر Telegram Bot API. يمكنك تعديل `MAX_UPLOAD_MB` إذا كانت بيئة Bot API لديك تدعم حداً مختلفاً، مع مراعاة حدود تيليجرام.

## ملاحظات تشغيلية
- Railway يحاسب على موارد التشغيل والاستهلاك وفق خطتك.
- لا ترفع ملف `.env` أو التوكن إلى GitHub.
- تحديث yt-dlp دورياً مهم لأن مواقع الفيديو قد تغير آلياتها.
- لا تستخدم البوت لتنزيل قوائم تشغيل؛ المشروع مضبوط على فيديو واحد لكل رابط.
- قد تفشل بعض الروابط بسبب قيود العمر أو المنطقة أو تسجيل الدخول أو تغييرات المنصة.
